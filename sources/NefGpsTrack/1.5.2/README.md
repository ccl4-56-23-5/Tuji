# 途记 1.5.2

Android 软件包名为 app.nefgpstrack，版本码为 14。Android 与 Windows 共用 shared/ui。

- Android 26–33 使用 AndroidX 离线模型换算平均海平面高度，34 及以上调用系统能力。保留原始椭球高度与海拔来源。单点采集给海拔换算最多 10 秒。
- Windows 修复精确命中空海拔节点时遗漏估算的问题，只在间隔不超过 120 秒的已知海拔节点之间估算，并记录来源。
- 手机页面、回看、确认弹窗与诊断区支持连续过渡、反向切换和减少动态效果。

见仓库根目录的 [构建说明](../../../BUILD.md)、[验证记录](../../../VALIDATION.md) 和本目录的 [维护文档](维护文档.md)。
