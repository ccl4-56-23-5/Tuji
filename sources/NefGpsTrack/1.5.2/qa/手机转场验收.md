# 途记 1.5.2 手机转场

## 实现与边界

手机使用浏览器原生 Web Animations API，页面退出和进入同时进行，`cubic-bezier(.22,.8,.25,1)` 提供非线性缓动。新操作先读取旧动画的当前位置和透明度，再取消旧动画并朝新目标继续；完成回调核对当前动画身份，避免被已取消的操作覆盖。手机的每页拥有独立滚动容器，切页保留滚动位置，不受长短页面改变文档高度的影响。Windows 仍沿用原页面布局。

覆盖记录、路径库、设置、回看、删除确认、导出及权限错误提示、诊断展开与收起、短提示进入与退出。系统定位权限面板、系统设置和系统文件选择器由 Android 提供其转场。API 33 以上通过 `OnBackInvokedCallback` 接入系统返回，旧版本通过 `onBackPressed`；返回顺序是当前弹窗、待加载路径、已展开诊断、回看→路径库、其他根页→记录，记录首页才交给系统退到后台。这里接入的是完成后的系统返回事件，并非随系统返回手势进度联动的预测性动画。

`prefers-reduced-motion` 下立即落到最终状态；运行中开启减少动态效果也会结束现有动画。所有退出页及隐藏页设为 `inert`，避免触碰或键盘访问。异步路径读取带请求序号及导航版本，用户切页或返回之后到达的数据不再强制打开回看。

海拔详情将 `interpolated-msl` 显示为“估算”。`alt=null` 继续显示未知；椭球高另列并标明非海拔，海拔精度只在有值时出现。
