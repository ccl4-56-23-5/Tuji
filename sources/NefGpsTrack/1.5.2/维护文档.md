# 途记 1.5.2 维护文档

Android Java 工程在 android，Windows Python 工程在 windows，安装器在 installer。先修改 shared/ui，再用根目录的 build-android.ps1 同步 Android 资源并构建。Windows 打包直接读取共享资源。构建工具、CLP 的本地口令配置及安装方式见 [BUILD.md](../../../BUILD.md)。

Android 的 AltitudeResolver 在定位工作线程换算 MSL。TrackDb v4 保留海拔来源、精度和原始椭球高度，已保存的历史路线不会自动重算。Windows 的 altitude.py、smoothing.py、curve.py 和 time_match.py 负责同刻海拔选择、分段处理、求值和照片匹配。估算标为 interpolated-msl。

Windows 安装器沿用原安装身份并保留安装目录内的 data。Android 使用 Release 签名包覆盖原版，应用标识为 app.nefgpstrack。公开源码自行签名的 APK 需要使用相同证书才能覆盖已有安装。

核验入口见 [VALIDATION.md](../../../VALIDATION.md) 与 qa。旧仓库源码可按 v1.5.1 标签查阅。
