本版Windows交付形态是**安装器**`NefGpsTrack-Setup-1.5.1.exe`（48,827,379字节；自研，代码在`installer\`），主程序作为载荷内嵌，并保留一份便携主程序`NefGpsTrack-Windows-1.5.1.exe`（31,500,225字节）作对照，两者逐字节一致。装出来的程序是`<安装路径>\途记.exe`，窗口标题`途记 1.5.1 · NEF GPS Studio`（标题字符串沿用前版，未随照片格式扩展改名），界面嵌入`../shared/ui`同一份文件。运行依赖系统WebView2。**本地数据随安装路径走**：路径库是`<安装路径>\data\路径库`（轨迹用可读文件名，如`2026-09-24_1355_连续_115点.clp`），界面偏好是`<安装路径>\data\程序数据\settings.json`，都不再写`%LOCALAPPDATA%`（源码运行时数据根是仓库根的`data`，可用`--data-dir`覆盖）。

安装：检测到已安装则显示原位置与版本、只给「开始升级」且**不询问路径**（按原路径覆盖、`data\`一字不动）；未安装则默认`%LOCALAPPDATA%\Programs\途记`并可改选，可写性用真实写探测，安装器与主程序都不提权。发现旧版数据目录`%LOCALAPPDATA%\NefGpsTrack`时自动迁移轨迹与偏好到`data\`下，**原目录整份保留不删**。卸载由主程序`--uninstall`完成：问两次（是否卸载 / 是否并删数据），删注册表项与开始菜单快捷方式，再由脱离的`cmd`清理安装目录。

本版其余改动：**照片补录扩展为多格式**（NEF / DNG / JPG / JPEG / PNG / HEIC / HEIF，唯一来源`exiftool_io.py::SUPPORTED_SUFFIXES`，`is_supported_photo()`/`file_type_ok()`把关，`batch.py::scan_photos()`与保留原扩展名的临时副本；写入链路对四种容器通用、**不按格式分支**，详见完整维护文档8.7节）；**四维平滑**（曲线`pchip-4d-v2`新增`alt`子曲线，`smooth_altitude()`海拔平滑，`_fit`未改）；**已有定位只按经纬度海拔判定**（`ExifTool.has_existing_position()`，空GPS IFD不再被拦住）；**照片编号与匹配位置面板**（`#`序号列、带编号`div.photo-pin`、行↔图钉双向联动、最多一处高亮）；**照片补录页重构**（左表单+右列`.photo-side`，处理进度与匹配位置等宽同列，写入按钮移到地图下方，电脑端常显且地图懒初始化）。写入仍不产生任何表格文件。

EXE支持`--self-check <JSON> [样片]`、`--ui-check <JSON>`、`--uninstall`（加`--silent`即静默并保留数据）与`--data-dir <路径>`；检查记录写入指定JSON路径；`--ui-check`会在记录旁创建`ui-check-routes`临时路径库与`ui-check-prefs.json`临时偏好，核对为空后再回收，不作为正式输出子目录保留。安装器另有`--probe`、`--silent-install <目录>`、`--silent-upgrade`、`--no-migrate`，以及测试用的`--reg-root`、`--shortcut`。
